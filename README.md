# DROP THE DECK: public feed

The read-only broadcast feed for the VRChat world DROP THE DECK: the Top 100 board, the season and the week's ghost
decks, mirrored every 10 minutes from the game server so every instance can read them from a trusted github.io URL.
`feed/config.json` holds the world-side switches (`crossfade`, `minBuild`, `motd`). Nothing else lives here.
